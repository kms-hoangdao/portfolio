# Hoang Helios — Portfolio

Personal portfolio for **Viet Hoang Dao** (Hoang Helios) — Software Engineer based in Da Nang, Vietnam.

Live site sections: about, skills, experience, selected projects, photography (Unsplash), contact.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- lucide-react

## Local development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## Editing content

All copy and data live in [`src/data/portfolio.ts`](src/data/portfolio.ts) — profile, skills, experience, projects, and photography links. Edit there; HMR picks it up.
